# Titan Zero Front Desk — archived Pro add-on PLAN (not a separate plugin)

> **Architecture superseded 2026-11-15.** This repository is retained as historical specification/reference material. **Do not build, ship or ask customers to install a Front Desk Pro add-on.** There is no verified installable Pro release to migrate.

## Authoritative one-plugin product structure

Install **one** Titan Zero Front Desk WordPress plugin:
1. **Free** — complete local booking, customer, calendar, deterministic enquiry/rules engine, basic opt-in hosted AI allowance.
2. **Titan Zero AI Assistant** — hosted full conversational assistance activated through the *same installed plugin* (no Pro purchase or second ZIP).
3. **Titan Zero AI Agent Team** — hosted specialist agents for enquiries, booking, quote intake, callback/follow-up and, when provisioned, voice; separate upgrade in the *same plugin*.

All local WordPress functionality distributed in Free must remain fully functional without remote licensing or caps. Charge only for genuine external hosted processing/orchestration/communications. Customer opt-in, privacy, tenant scopes, action receipts and downgrade must work in the one plugin.
