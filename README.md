# Titan Zero Front Desk Pro + AI Assistant

**Commercial plan:** a single paid Front Desk Pro product includes the **advanced AI Assistant**. There is **no separately sold Front Desk AI Assistant tier**.

This repository will deliver **one separately installable WordPress Pro extension** to the complete Front Desk Free plugin. It bundles the premium local forms, CRM, reporting, location/workflow management and Assistant interfaces. Model inference and embeddings execute through the shared opt-in Titan AI Proxy, funded as an included Pro hosted service with usage/fair-use terms to be validated and published. There is no separate Assistant subscription or installation.

**Agent remains a distinct upgrade:** autonomous receptionist, live voice, autonomous messaging, signed cross-app tasks, action approvals and receipts. Do not insert these autonomous capabilities into Pro Assistant.

**Free remains complete:** standard WordPress booking, rules-first enquiry tools and basic limited hosted AI; local code and current bookings must not be gated. Pro's local functions must work without AI network availability; do not ship provider credentials in the plugin.

**Status:** this repository currently contains development plans and CI setup. **No verified installable Pro/Assistant release has been produced yet.** Do not advertise it as complete.
